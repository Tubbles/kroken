## micro integration lands as a bundled plugin with buffer anchors

- **Where**: the plugin lives in the Tubbles/micro fork as `runtime/plugins/kroken/` on branch `kroken`, not in this repository, as PLAN.md milestone 2 intended. Bundled means a `make build` of the fork carries it, with no plugin manager step.
- **Paste-back strategy**: editor marks (strategy 1 in `doc/editor-integration.md`), implemented as buffer anchors added to the fork on top of its existing text-edit listener hook. Text search was rejected: micro's `FindNext` is line-based, so it can never find a multi-line selection, and it picks the wrong occurrence when the selection text is duplicated. The anchor's text is compared with the sent selection before pasting, so edits inside the region cancel the paste instead of clobbering them.
- **Three corrections to the old micro sketch**, now recorded in `doc/editor-integration.md`: stdout and stderr arrive mixed in the exit callback, the exit status must be read from the job's `ProcessState`, and `FindNext` cannot match across lines.
- **No kroken changes were needed.** The protocol held up as designed: `--selection-file` for the stdin micro cannot close, 1-based inclusive positions, stdout verbatim, status on stderr, exit codes.

## Installation and releases

Tags: #decision #release #install

- `scripts/install.sh` copies the binary to `<prefix>/bin`; a symlink stays the documented option for development. No package manager format yet.
- Releases are cut by pushing a `vX.Y.Z` tag. The workflow rebuilds from scratch and fails when the binary's reported version differs from the tag, so a forgotten `VERSION` bump cannot ship. CI artifacts expire after 90 days, which is why a release is the distribution channel for machines without the toolchain.
